# 重力レンズmod検証報告

2026-10-04、ワークスペースのWinMUGEN Plus、640×480、16bit、GameSpeed=60、ウィンドウモードで検証しました。利用者が選択した合格基準は **平均約60fps** です。全フレーム16.67ms以下という判定ではありません。

## 最終配布ビルドの結果

元キャラクターは `WinMugenPlus/chars/kfm-gravitational-lens-test`。元の14ファイルを保持し、追加CNSと別名DEFを使った隔離コピーで実行しました。半径512px、Einstein半径70px、軟化半径18px、中心(320,240)、描画優先度境界0を指定しました。これらはテスト条件であり、利用者の実運用パラメーターではありません。

| 測定・検査 | 最終結果 |
|---|---:|
| 連続したエフェクト適用中の提示回数（120回のウォームアップ除外後） | 5,878 |
| **平均描画FPS**（描画フレーム間隔の平均から計算） | **59.873247 fps：合格** |
| 描画フレーム間隔：平均 / P99 / 最大 | 16.701950 / 31.984100 / 37.835400 ms |
| 描画フレーム間隔が16.6667msを超えた回数 | 913 |
| 変形処理：平均 / P99 / 最大 | 2.188101 / 3.952900 / 9.029800 ms |
| 同一フレームの参照元画素バイト列との比較 | 307,200画素、不一致0 |
| 変形によって参照位置が変わった画素 | 200,212 |
| 半径外の変化 | 0 |
| 元の描画順とフック経由の描画順 | `-3 → 0 → 0 → 3`、一致 |
| 描画ノード内容の変更 | 0 |
| 手前の不透明KFM画素の対照比較 | 30,248画素、不一致0 |

FPSは変形直前の描画境界でQPCを読み、各提示番号が1ずつ増える連続区間で求めた、エフェクト適用フレームの平均描画FPSです。表示処理の末尾やモニター走査のタイムスタンプではありません。エフェクト処理時間だけからFPSを換算した値ではありません。ゲームは不可視状態で動かし、隔離設定のPauseOnDefocusを0にしました。モニターの走査・表示遅延は測っていません。原本の設定は変更していません。描画フレーム間隔のばらつきは残っており、全フレーム60fpsを保証する結果ではありません。

変形時間には元画像の退避、計算DLL呼出し、描画バッファへのコピーを含みます。CNSで形状を変更した瞬間のカーネル再作成、後続スプライト描画、提示処理、CSV書込は含みません。平均FPSにはウォームアップ後のゲーム全体の処理が反映されます。停止時にCSVの末尾が途切れた場合だけ不完全行を除外します。遅いフレームを性能集計から除外する処理はありません。

## 検査方法と証跡

数学DLLを呼ばないPython検査器が、保存した変形前画像とCNSパラメーターから参照座標を再計算し、変形後画像の全画素を比較しました。最近傍コピーの16bit値が一致することにより、補間・色変換・パレット変更をしていないことを検査しています。

レイヤー検査では、最初の適用フレームに限り、同じ描画ノードを未変形の対照バッファにも描きました。エンジンが選んだ元のノード順、実際のノード順、ノードの56バイトが変わっていないことを比較しています。境界以降に元のKFM描画が更新した不透明画素を比較しました。すべての半透明・加算・特殊描画モードの等色保証ではありません。検査用の二重ラスタライズは配布時には無効です。

本リポジトリには [集計結果](verification/live-results.json) と [元の配布DLLのハッシュ](verification/original-build-hashes.json) を収録しています。RAW・PNG・キャラクター素材は開発ワークスペースに保存されており、このリポジトリには含めません。集計結果内のファイル名とハッシュは元の検証記録です。

## 計算DLL単独

`lens-math-test.exe` で1/2/3/4 bytes/pixelの全画素、行パディング、末尾ガード、強度0の恒等変換、無効引数、端・移動中心を検査し、合計1,228,800画素の比較に合格しました。半径512px・32bit・移動中心の600回測定は平均1.952014ms、P99 2.638800ms、最大3.253900ms。これは単独DLLの性能で、MUGENのFPSとは区別しています。
